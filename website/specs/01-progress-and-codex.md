# 01 存檔、圖鑑與稱號規格

## 存檔（Progress）

- 存在瀏覽器 `localStorage`，key：`k8s-cloud-island-save-v1`
- 內容：
  - `nickname`：玩家暱稱，去頭尾空白後 1–12 字
  - `clearedDays`：已過關的 Day（1–30），不重複、遞增排序
  - `seenCharacters`：點開過影子的角色 id
  - `unlockedCharacters`：答對、變成彩色的角色 id
- 讀不到、JSON 壞掉、版本不符時，回到全新存檔，不拋錯
- 每次狀態改變立即寫入

## 圖鑑（Codex，Day 31）

- 每個角色一開始是**影子**，只顯示 `riddle`（一段敘述）
- 點影子 → 記錄為「看過」，打開選擇題（`options` 4 選 1）
- 選到 `answer` → 角色變彩色，顯示 `name`、`k8sName`、`description`、登場 Day
- 選錯 → 不扣分、可以再猜，被選過的錯誤選項淡掉
- 答題判斷忽略大小寫與前後空白

## 稱號

依完成度計算，取最高的一個：

- 未開始：「迷路的旅人」
- 過關 ≥ 1 或圖鑑 ≥ 1：「登島新手」
- 過關 ≥ 10：「泡泡吹手」
- 過關 ≥ 20：「燈塔村見習生」
- 過關 = 30：「雲之島守護者」
- **過關 = 30 且圖鑑全部點過並答對**：「K8s 雲之島統治大王」

取得統治大王時，跳出證書頁 `/ruler`，證書上寫玩家暱稱。
