# 04 美術規範：雲之島角色與色票

## 整體風格
- 溫暖水彩繪本風：天空淡藍、雲朵奶油白、草地綠、樹皮棕
- 亮橘 `--accent #f08a24` 是唯一強調色，每個角色只用在一個小重點（旗子、蝴蝶結、指針、封蠟）
- 色票與間距一律取 `src/presentation/styles/tokens.css`，元件內不新增色碼

## 角色 SVG 規格
- 位置：`src/presentation/components/characters/art/<id>.vue`，檔名即角色 id
- `viewBox="0 0 120 120"`，不寫死寬高，由父層 CSS 控制
- 背景透明、不畫底框
- 描邊：棕色 `#6b4f3a`，線寬 2–3，圓角端點與接點
- 水彩感用純色加半透明疊色與白色高光，不用 gradient／filter id（同頁多隻時 id 會衝突）
- 只用 `<template>`，不寫 `<script>`
- 使用尺寸 48–120px；新角色在 48px 影子版仍可辨識才能合併

## 影子規則（圖鑑未解鎖）
- 未解鎖時套 `filter: brightness(0)`，所以輪廓本身要能辨識
- 辨識點必須長在輪廓外緣：帽子、道具、翅膀、把手，不能只靠內部花紋
- 透明物件（泡泡、上限線的杯子）影子會呈半透明灰，屬預期效果

## 角色辨識重點
- 小鳥（Container）：圓滾藍綠色、奶油肚、橘色鳥嘴；其他鳥角色的嘴改用淡橘，避免搶強調色
- 泡泡（Pod）：透明球加頂端橘色蝴蝶結與吊繩
- 巢樹（Node）vs 記憶樹（etcd）：巢樹右側伸出枝條托鳥巢；記憶樹樹冠更寬並垂掛小牌子
- 管理者類靠帽子與道具區分
  - 選樹官：探險帽加樹形路牌
  - 巡邏隊長：寬簷巡山帽加望遠鏡
  - 部署管家：海軍帽加 v1→v2 卷軸
  - 編號泡泡管理員：圓筒帽加 0／1／2 編號泡泡
  - 守樹隊長：羽飾頭盔加樹紋盾牌
  - 守門員：小帽加直立大鑰匙
- 圖騰柱系列共用同一根柱子，靠底座區分
  - totem：單獨一根，翅膀加橘色舵輪紋章
  - totem-inner：站在浮島上（島內）
  - totem-gate：旁邊一棵開了門的樹（樹門）
  - totem-dock：站在碼頭上，旁邊有帆船與水波（碼頭）
- 容易混淆的物件組
  - 委託單（Job）有折角與封蠟緞帶；借用單（PVC）是有撕線缺口的票根
  - 食物桶（Volume）有提把；食盆（Volume Mount）矮寬無提把
  - 定時鐘（CronJob）有雙鈴與腳；旋鈕（HPA）是刻度環加 +／−
