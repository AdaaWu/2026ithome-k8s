# 07 RWD 規格：手機為主，往上延伸到平板與桌機

## 鐵律

- **手機版視覺一個像素都不能變**：`tests/visual/mobile.spec.ts` 的 360 與 390 基準截圖必須全綠，不准更新這兩組基準
- 只能「往上加」：新樣式一律寫在 `@media (min-width: 768px)` 或 `@media (min-width: 1024px)` 裡，不修改、不刪除任何既有的宣告
- 需要新增 DOM 時，手機版看起來必須完全一樣（基準截圖會把關）；能用 CSS 做到就不加 DOM
- 唯一允許寫在媒體查詢外的新樣式：讓桌機專用的新 DOM 在手機上 `display: none`
- 不改任何遊戲邏輯、存檔、音訊行為；只動版面與樣式
- 互動仍以 tap／click 為主；桌機可以加 hover 效果，但不可以讓功能依賴 hover

## 斷點

- `< 768px` 手機：現狀，不動
- `768px–1023px` 平板：內容最寬 720px 置中，卡片可以兩欄
- `≥ 1024px` 桌機：內容最寬 1120px 置中，善用左右空間做雙欄或多欄
- `≥ 1440px` 大螢幕：不再加寬內容，用背景（天空、雲）填滿

## 版面系統

- `#app` 在 768px 以上取消 480px 上限，改由各頁面自己的容器決定內容寬度
- 背景（天空漸層、雲、紙紋）在桌機要滿版，不能出現左右兩條空白
- 頂部列（TopBar）在桌機滿版、內容置中，左右按鈕貼齊內容容器邊緣
- 字級：桌機可以放大，但本文最大 18px，大標題用 `clamp()` 隨寬度成長
- 點擊目標維持 ≥ 44px

## 各頁面目標

- **起始畫面**：滿版天空，多層雲朵從左到右緩慢飄過（視差：遠的慢、近的快），雲之島主圖置中漂浮；暱稱卡片置中，不要撐滿寬度
- **島嶼地圖**：桌機左側固定的玩家資訊欄（暱稱、稱號、進度、圖鑑入口），右側關卡路徑；六幕可以排成多欄或更寬的蛇行路徑
- **角色圖鑑**：網格在桌機變成 6–8 欄；影子題的底部彈出面板改成置中對話框
- **關卡頁**：開場頁改成左圖右文；遊戲舞台維持 360px 設計，在桌機置中並可等比放大（最多 1.4 倍），兩側留白用天空背景
- **過關頁、證書頁、找不到頁**：置中卡片，最寬 640px

## 遊戲舞台倍率

遊戲內容以 360px 設計，桌機用 CSS `zoom` 整塊等比放大，依視窗高度分級，確保舞台與控制列一屏看完：

- 平板 768px 以上：1.15
- 桌機 1024px 以上：高度 ≥ 1000 為 1.4，930–999 為 1.3，870–929 為 1.2，800–869 為 1.1，低於 800 為 1.0

## 驗收

- `PW_PORT=<專屬 port> bunx playwright test --project=mobile-360 --project=mobile-390` 全綠
  - 基準截圖取自 RWD 之前的程式；比對容許 100 個像素，只用來吸收文字抗鋸齒雜訊，版面位移會遠超過這個量
  - 截圖前固定亂數、關閉音訊、凍結時鐘、等動畫與轉場結束、字型走本機快取，結果不受網路與機器負載影響
- 新增桌機視覺測試 `tests/visual/desktop-<區塊>.spec.ts`，在 tablet-768、desktop-1280、desktop-1920 三個 project 產生基準
- `bunx vue-tsc -b`、`bunx vitest run` 全綠
